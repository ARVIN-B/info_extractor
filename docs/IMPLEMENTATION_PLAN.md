## تصمیم‌های MVP

- پایگاه‌داده SQLite برای شروع؛ در تنظیمات قابلیت تغییر مسیر فایل پایگاه‌داده حفظ می‌شود.
- دو منبع نقشه مستقل و قابل انتخاب‌اند. آگهی‌های شخصی classifieds در نسخهٔ نخست وارد نمی‌شوند.
- جست‌وجو حداکثر از ۳ عبارت قطعی برای هر trade استفاده می‌کند؛ نتیجهٔ هر منبع با شناسه و پاسخ خام همان منبع ثبت می‌شود.
- جست‌وجوی سراسر ایران فقط از شهرهای شاخصی که واقعاً در Neshan قابل جست‌وجو هستند نمونه‌برداری می‌کند؛ این پوشش جامع نیست.
- استفاده از Celery به Redis نیاز دارد. برای اجرا باید Redis و یک worker جداگانه راه‌اندازی شوند؛ درخواست وب فقط job را صف می‌کند.
- بسته‌های runtime با نسخهٔ دقیق در `.venv` نصب می‌شوند. MCP serverها از مسیر executable همان محیط اجرا می‌شوند؛ هیچ نصب سراسری انجام نمی‌شود.
- شمارهٔ تلفن با الگو بررسی می‌شود، نه با تماس؛ اعتبارسنجی قالب، مالکیت یا فعال‌بودن را اثبات نمی‌کند.

## وابستگی‌های مورد انتظار

نسخه‌های دقیق نهایی در `requirements.txt` و راهنمای استقرار ثبت می‌شوند. Connectorها بر مبنای `neshan-mcp==0.2.0` و `balad-mcp==0.2.0` هستند. SDKهای Django، Celery/Redis، MCP و Excel نیز در `.venv` نصب خواهند شد.
