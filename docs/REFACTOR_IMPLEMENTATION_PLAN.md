# Refactor implementation plan

این چک‌لیست بر اساس `docs/refactor.md` و درخواست تکمیلی کاربر تهیه شده است.

## بررسی پایه

- [x] خواندن کامل سند `docs/refactor.md` و استخراج الزامات جست‌وجو، خروجی، ایمنی و تست.
- [x] بررسی وضعیت Git و حفاظت از دو فایل staged قبلی؛ فایل نمونهٔ خام تغییر نمی‌کند.
- [x] بررسی مدل‌های داده، فرم جست‌وجو، viewها، Celery، ثبت MCPها، تنظیمات و وابستگی‌ها.
- [x] تکمیل بررسی ابزارها و adapterهای فعلی Neshan، Balad و Emalls و انتخاب مسیر کم‌ریسک مهاجرت.
- [x] ثبت وضعیت baseline برای تست‌ها و مهاجرت‌های دیتابیس: system check سالم؛ ۹۰ تست فعلی پاس؛ دو migration آخر هنوز روی SQLite محلی اجرا نشده بودند.

## پیاده‌سازی

- [x] محدود کردن registry، adapterها، تنظیمات، فرم‌ها و وابستگی‌های MCP به Neshan، Balad و Emalls.
- [x] افزودن تعداد موبایل درخواستی به فرم و SearchJob، با سقف تنظیم‌پذیر.
- [x] افزودن رکورد یکتای موبایل در محدودهٔ هر Job و ذخیرهٔ منبع/نشانی با قید یکتایی دیتابیس.
- [x] استفاده از استخراج و canonicalization موجود برای موبایل فارسی/عربی/لاتین و رد تلفن ثابت/شمارهٔ نامعتبر.
- [x] افزودن فیلتر تلفن به ابزارهای MCP فقط وقتی در schema زنده پشتیبانی می‌شود.
- [x] افزودن جست‌وجوی SearXNG و crawl محدود دامنه‌های عمومی با Firecrawl self-hosted.
- [x] اجرای چهار lane به‌صورت هم‌زمان، dedupe دیتابیس و توقف امنِ کارهای غیرضروری پس از رسیدن به هدف.
- [x] نمایش شماره و منبع به‌همراه نام کسب‌وکار، وب‌سایت، نشانی و توضیحات در صورت وجود در UI و خروجی JSON/Excel.
- [x] افزودن شمارش هدف/واقعی، وضعیت هر lane و خطاهای مستقل به صفحهٔ Job.

## اعتبارسنجی و مستندات

- [x] تست‌های آفلاین برای استخراج، canonicalization، dedupe بین منبع‌ها، هدف، موازی‌بودن laneها، خطای 429/timeout و خروجی‌ها؛ ۱۴ تست پاس شدند.
- [x] اجرای `manage.py check`, تست‌های پروژه و `makemigrations --check` با Python داخل `.venv`؛ همه موفق شدند.
- [x] به‌روزرسانی README و نمونهٔ env؛ ثبت راه‌اندازی سرویس‌های SearXNG و Firecrawl.
- [x] بازبینی نهایی diff، حفاظت از `.env` و فایل نمونهٔ خام؛ هر دو endpoint در `.env` پیکربندی شده‌اند اما از این محیط با `ConnectError` قابل دسترسی نبودند.

## تکمیل خروجی کسب‌وکار و پایداری وب

- [x] افزودن نام، وب‌سایت، نشانی و توضیحات اختیاری به مدل نتیجه، UI، JSON و Excel؛ شماره و منبع همچنان فیلدهای اصلی هستند.
- [x] افزودن migration با backfill نام/وب‌سایت نتایج قبلی از رکوردهای کسب‌وکار موجود.
- [x] کاهش جست‌وجوی وب به یک query برای هر Job، حفظ عنوان/snippet، crawl تا ۸ صفحه و توقف crawlهای بعدی پس از رسیدن به هدف.
- [x] ثبت شمارندهٔ درخواست SearXNG و تمام POST/pollهای Firecrawl؛ خطای اتصال با سرویس و میزبان مشخص و بدون افشای query/credential ثبت می‌شود.
- [x] کاهش فراخوانی‌های Emalls با `em_shops` و فراخوانی جزئیات فقط برای فروشگاه فاقد موبایل.
- [x] اجرای تست‌های regression، migration check و system check؛ ۱۷ تست و هر دو check موفق شدند.
- [x] بررسی نهایی `.env` (بدون تغییر)، diff و وضعیت واقعی دسترسی سرویس‌های وب؛ هر دو endpoint در این محیط ConnectError می‌دهند.
